# Performance Test Plan — Uptime Kuma

## System under test
- Uptime Kuma `louislam/uptime-kuma:2` (Docker, port 3001)
- Host: WSL2 Ubuntu, 8 vCPU / 16 GiB RAM (typical dev box)
- Network: loopback (`localhost`) — eliminates LAN variance so we measure server-side cost

## High-risk modules (from midterm risk analysis)
| # | Module | Why it's high-risk | Endpoint(s) hit |
|---|---|---|---|
| 1 | Status-page rendering | First-page load for every public viewer; reads from DB + assembles JSON of monitors, groups, incidents | `GET /api/status-page/<slug>` |
| 2 | Status-page heartbeat | Polled continuously by every open status page; payload grows with retained heartbeats | `GET /api/status-page/heartbeat/<slug>` |
| 3 | Badge endpoint | Hot-linked from third-party README files — high traffic, generates SVG per request | `GET /api/badge/<id>/status` |

## Scenarios
| # | Name | Concurrency | Duration | Goal | Pass thresholds |
|---|---|---|---|---|---|
| S1 | Normal load | 10 VU | 60 s | Baseline behavior | p95 < 250 ms, error < 1% |
| S2 | Peak load | 50 VU | 60 s | Expected peak | p95 < 800 ms, error < 2% |
| S3 | Spike | 5 → 100 VU step | 60 s | Sudden surge | p95 < 1500 ms, error < 5% |
| S4 | Endurance / soak | 20 VU | 5 min | Memory leaks / GC pauses | p95 stable across windows, error < 1% |

VU = virtual user (one Python thread issuing requests back-to-back with no think-time, which is the worst case).

## Metrics collected
- HTTP response time: average, median, p95, p99, max
- Throughput: requests per second (RPS)
- Error rate: % of non-2xx responses + connection errors
- Container resource usage: CPU %, memory MiB (sampled via `docker stats --no-stream` every 2 s)

## Tooling
- Python 3.12 stdlib (`urllib.request`, `concurrent.futures`, `statistics`)
- `docker stats` for resource sampling
- Results saved as JSON + CSV under `tests/experimental/results/`
- Markdown summary tables generated by `summarize.py`

## Execution command
```bash
python3 tests/experimental/performance/load_runner.py \
    --scenario all \
    --base-url http://localhost:3001 \
    --out tests/experimental/results
```
